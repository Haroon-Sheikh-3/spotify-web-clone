# Spotify Web Clone

An interactive web music player clone inspired by Spotify, built with modern front-end technologies.

## 🚀 Features

- Custom audio playback engine (play, pause, track navigation)
- Interactive tracklist & dynamic queue control
- Responsive visual UI with dark mode styling

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## 💻 How to Run

Simply clone the repository and open `index.html` in your browser.

This is a front-end practice project. No backend or streaming server is included — the focus is on layout, state, and interaction using only client-side technologies.

## 📝 Purpose

Built as a learning project to recreate the feel of Spotify's web player as a frontend interface. The focus was on layout, state, and interaction rather than a real audio backend.

⚙️ Development some functionality received AI-assisted support; implementation adjustments, tweaking, and refinement were personally handled.
