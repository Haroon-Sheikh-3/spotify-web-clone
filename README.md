# 🎵 Interactive Spotify Web Application Clone

A dynamic web music player inspired by Spotify, built with modern front-end technologies.

## 🚀 Features
- Custom audio playback engine (play, pause, track navigation)
- Interactive tracklist & dynamic queue control
- Responsive visual UI with dark mode styling

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (ES6+)

## 💻 How to Run
Simply clone the repository and open `index.html` in your browser.
